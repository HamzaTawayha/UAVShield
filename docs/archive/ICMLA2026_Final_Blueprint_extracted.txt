1.1    Final Title

             CrossGuard: Runtime Cross-Layer Consistency Monitoring

1.2    Final Core Claim
       Agentic UAV systems can fail when an attacker injects planner-visible state that is
       locally plausible but inconsistent across perception, depth, telemetry, and command
       effects. CrossGuard detects these attacks by monitoring lightweight runtime invariants
       before the agent’s decisions become unsafe trajectories.

1.3    Contribution Bullets (Exact Wording for Paper)
    1. We formalize cross-layer consistency attacks—a class of adversarial manipulations that cre-
       ate contradictions between perception, telemetry, and control layers in agentic UAV archi-
       tectures.
    2. We demonstrate two concrete attack instantiations (Phantom Obstacle Injection and Teleme-
       try State Drift) and evaluate their mission-level impact on single-drone and multi-drone
       configurations.
    3. We propose CrossGuard, a lightweight runtime monitor using physics-based invariants to
       detect cross-layer inconsistencies with high accuracy and low latency.
    4. We evaluate CrossGuard on a PX4 SITL + MAVSDK + ROS2 testbed across two LLM
       backends, demonstrating that the vulnerability is architectural rather than model-specific.

5     Threat Model

5.1    Attacker Profile
• Goal: Cause mission failure (unsafe trajectory, waypoint miss, false abort) while remaining
  undetected by single-layer checks.
• Capability: Network-level MitM on ROS2 DDS topics and/or MAVSDK UDP telemetry stream.
  Confirmed realistic: ROS2 DDS discovery is unauthenticated by default [3, 16]; MAVLink UDP
  is unencrypted [5, 8].

• Key constraint: Attacker manipulates one layer at a time (perception OR telemetry), creating
  cross-layer inconsistency that CrossGuard exploits.
• Cannot: Modify PX4 firmware, modify agent code/model weights, access physical sensors di-
  rectly, compromise all layers simultaneously.

5.2    Why Defensible
1. ROS2 topic injection is a published, demonstrated vulnerability [3, 16].
2. MAVLink over UDP is unencrypted in development and many field deployments [5].
3. “Attack one layer, exploit cross-layer trust” is novel and well-scoped—neither trivial nor unre-
   alistic.
4. Even with SROS2 enabled, a compromised node within the trust domain can still inject [3].

Algorithm 1 CrossGuard Runtime Monitor
 1: Input: Perception stream P, depth frames D, telemetry T , commands C
 2: Parameters: Thresholds τ1 , τ2 , τ3 ; violation limit Vmax = 3; window W = 5
 3: Initialize: V ← 0
 4: while system active (10 Hz) do
 5:   v1 ← CheckPercDepth(Pt .claimed range, Dt [Pt .px], τ1 )

11:   else

13:   end if

class DriftProxy:
    """UDP proxy: PX4(14540) <-> Proxy(14541) <-> MAVSDK(connects to 14541)
    Intercepts GLOBAL_POSITION_INT, adds position drift."""

       def __init__(self, drift_rate_ms=0.10):
           """drift_rate_ms: meters per second of position drift"""
           self.drift_rate = drift_rate_ms # 0.10 m/s = 6 m/min
           self.attack_start = 20.0   # seconds
           self.attack_duration = 70.0 # enough for 7m drift
           self.t0 = time.time()

       def modify_packet(self, msg):
           elapsed = time.time() - self.t0
           if not (self.attack_start <= elapsed <= self.attack_start + self.attack_duration):
               return msg # pass through unmodified

          dt = elapsed - self.attack_start
          drift_m = self.drift_rate * dt # linear drift
          drift_deg = drift_m / 111139.0 # meters to degrees (lat)

          # Modify lat/lon (stored as int32 * 1e7)
          msg.lat += int(drift_deg * 1e7)
          msg.lon += int(drift_deg * 1e7 * 0.7) # diagonal
          return msg
