# PhD Attack Integration Guide

This page explains how to test attack scenarios against the current UAVShield
detector. It is written for an external attack runner such as the one that
produced the `Results/` folder.

## What UAVShield Expects

UAVShield is not a replacement planner. It is a gate placed before the planner
trusts a state or memory update.

```text
attack runner generates observation/update
          |
          v
UAVShield scores the current telemetry window
          |
          v
allow update OR quarantine update
          |
          v
planner receives only allowed state/memory
```

The current detector is trained on UAV-SEAD telemetry windows. It expects a
rolling multivariate UAV state window with the same feature layout generated by:

```bash
python scripts/uav_sead_build_moment_windows.py --include-log-level-anomalies
python scripts/augment_uav_sead_physics_features.py
```

The deployable model artifact is:

```text
data/uav_sead/moment_windows/statistical_features_family_threshold_search_1000/family_threshold_search_model.joblib
```

The threshold table is:

```text
data/uav_sead/moment_windows/statistical_features_family_threshold_search_1000/best_thresholds.json
```

## Recommended Hook Points

Add UAVShield at one or both of these points.

### 1. Observation Gate

Call UAVShield immediately after an attack modifies the agent-visible
observation, but before the planner prompt is rendered.

This catches attacks like:

```text
fake GPS / position update
fake altitude or velocity update
fake battery or safety telemetry
fake estimator or actuator state
```

### 2. Memory-Write Gate

Call UAVShield before `memory_written` is committed.

This is the right hook for memory poisoning attacks such as:

```text
s1 ghost target/person memory
s3 false critical safety constraint memory
```

If UAVShield flags the update, do not write that candidate into memory. Store it
in a quarantine list instead.

## Minimal Runtime Contract

Your attack runner should call a function with this behavior:

```python
verdict = uavshield_check(
    rolling_telemetry_window=current_window,
    candidate_update=agent_visible_observation_or_memory_candidate,
)
```

Expected output:

```python
{
    "allow": False,
    "score": 0.87,
    "family": "External Position",
    "threshold": 0.05,
    "action": "quarantine",
    "reason": "family score crossed calibrated threshold"
}
```

The planner should only receive the update when:

```python
verdict["allow"] is True
```

## Loading The Model

The saved joblib contains the trained classifier and the selected family
thresholds:

```python
import joblib

artifact = joblib.load(
    "data/uav_sead/moment_windows/statistical_features_family_threshold_search_1000/"
    "family_threshold_search_model.joblib"
)

model = artifact["model"]
thresholds = artifact["thresholds"]
class_names = artifact["class_names"]
source_feature_names = artifact["source_feature_names"]
```

The model expects statistical summaries of the rolling telemetry window, not raw
JSON. Use the same feature function used during training:

```python
from scripts.train_statistical_feature_baseline import statistical_features

x_features, _ = statistical_features(window_tensor, source_feature_names)
probabilities = model.predict_proba(x_features)
```

Where `window_tensor` has shape:

```text
[num_windows, num_channels, sequence_length]
```

For the current UAV-SEAD artifact:

```text
num_channels = 92
sequence_length = 64
```

## Decision Logic

Use the saved family thresholds:

```python
def decide(probabilities, thresholds, class_names):
    # probabilities is one row from model.predict_proba(...)
    candidates = []
    for class_id, item in thresholds.items():
        class_id = int(class_id)
        threshold = item["threshold"]
        score = probabilities[class_id]
        if score >= threshold:
            candidates.append((score - threshold, score, class_id))

    if not candidates:
        return {
            "allow": True,
            "score": float(1.0 - probabilities[0]),
            "family": "Normal",
            "threshold": None,
            "action": "allow",
        }

    _, score, class_id = max(candidates)
    selected = thresholds[class_id] if class_id in thresholds else thresholds[str(class_id)]
    return {
        "allow": False,
        "score": float(score),
        "family": class_names[class_id],
        "threshold": selected["threshold"],
        "action": "quarantine",
    }
```

## Important Limitation

The detector needs telemetry context. If an attack only inserts a text-like
memory claim and does not provide a corresponding telemetry/perception state,
then the attack runner must still pass the current rolling telemetry window.

For example:

```text
s1 ghost target memory:
  candidate_update = fake person location
  rolling_telemetry_window = drone state around the injection step

s3 false safety memory:
  candidate_update = fake critical safety status
  rolling_telemetry_window = drone state around the injection step
```

This is how UAVShield decides whether the memory update is physically consistent
with recent UAV behavior.

## Metrics To Report

Please report these before and after adding UAVShield:

```text
mission_success_rate
mission_failure_rate
any_false_belief_rate
fbar_post_injection_mean
rmfr_mean
ddr = defense detection rate
fpr = false positive rate on clean runs
fnr = false negative rate on attacked runs
ttc = time to correction, if the attack runner supports correction
```

Definitions:

```text
DDR = attacked updates flagged / attacked updates injected
FPR = clean updates incorrectly flagged / clean updates tested
FNR = attacked updates missed / attacked updates injected
```

The expected comparison is:

```text
attack-only baseline: defense_active = false
UAVShield run:        defense_active = true
```

## How To Update `events.jsonl`

When an update is blocked, add a defense object to the event:

```json
{
  "defense_active": true,
  "uavshield": {
    "allow": false,
    "score": 0.87,
    "family": "External Position",
    "threshold": 0.05,
    "action": "quarantine"
  },
  "memory_written": [],
  "memory_quarantined": [
    {
      "reason": "uavshield_flagged",
      "candidate": "original memory candidate here"
    }
  ]
}
```

For clean updates that pass:

```json
{
  "defense_active": true,
  "uavshield": {
    "allow": true,
    "score": 0.02,
    "family": "Normal",
    "action": "allow"
  }
}
```

```bash
python scripts/search_family_threshold_configs.py \
  --windows data/uav_sead/moment_windows/uav_sead_precise_physics_windows.npz \
  --output-dir data/uav_sead/moment_windows/statistical_features_family_threshold_search_1000 \
  --old-eval data/uav_sead/moment_windows/statistical_features_histgb/evaluation.json \
  --model hist_gb \
  --threshold-step 0.05 \
  --trials 1000 \
  --selection-metric accuracy
```
