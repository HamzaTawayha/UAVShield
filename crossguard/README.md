## Runtime Placement

The detector should run before the planner trusts a state or memory update:

```text
telemetry / perception / memory update -> UAVShield -> allow/quarantine -> planner
```

The current best detector artifact is generated by:

```bash
python scripts/search_family_threshold_configs.py \
  --windows data/uav_sead/moment_windows/uav_sead_precise_physics_windows.npz \
  --output-dir data/uav_sead/moment_windows/statistical_features_family_threshold_search_1000 \
  --old-eval data/uav_sead/moment_windows/statistical_features_histgb/evaluation.json \
  --model hist_gb \
  --threshold-step 0.05 \
  --trials 1000 \
  --selection-metric accuracy
```

The main output is:

```text
data/uav_sead/moment_windows/statistical_features_family_threshold_search_1000/family_threshold_search_model.joblib
```

Use it as a memory/observation gate in the attack runner: if UAVShield returns
`allow = false`, quarantine the candidate update and do not expose it to the
planner prompt or memory store.
